Medical Appointment No-Show Analysis Using Python
Project Overview
This project analyzes medical appointment data to identify factors associated with patient no-shows. The analysis focuses on demographic, medical, and social factors that may influence appointment attendance.

Dataset
The dataset contains information about 110,527 medical appointments, including patient demographics, chronic conditions, SMS reminders, scholarship status, and appointment attendance outcomes.

Project Objectives
Identify the overall no-show rate.
Analyze the relationship between SMS reminders and attendance.
Investigate the impact of age groups on no-show behavior.
Evaluate the influence of diabetes and hypertension.
Examine the effect of scholarship status on attendance.
Generate actionable healthcare insights.
Tools Used
Python
Pandas
Matplotlib
Jupyter Notebook
Data Cleaning
Removed unrealistic age values.
Checked for missing values.
Checked for duplicate records.
Created age groups for analysis.
